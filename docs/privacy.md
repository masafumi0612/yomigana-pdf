# よみがなPDF プライバシーポリシー

よみがなPDF は、ブラウザで開いた PDF の漢字によみがな（ルビ）を付ける Chrome 拡張機能です。このページでは、拡張機能が扱う情報と、その置き場所を説明します。

## まとめ

- 開いた PDF の中身・URL・設定・直した読みを、開発者や外部のサーバーに送りません。
- 漢字の読みは、拡張機能に入っている辞書を使って、お使いのパソコンの中で調べます。
- 名前・メールアドレスなど、個人を知る情報は集めません。
- 利用状況の計測・広告はありません。

## 扱う情報と置き場所

| 情報                                                    | 何に使うか                           | 置き場所                                                                    |
| ------------------------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------- |
| 開いた PDF（ウェブの PDF・パソコンに保存した PDF）      | 画面に出し、ルビを付けるため         | 保存しません。開いているあいだだけ使います                                  |
| 漢字の読みを調べた結果                                  | 同じ文を何度も調べないため           | 開いているあいだのメモリの中だけ。閉じると消えます                          |
| 設定（ルビの量・見た目・自動で開くスイッチなど）        | 次に開いたときも同じ設定にするため   | Chrome の同期用の保存先（下の「Chrome の同期」）                            |
| 直した読み（言葉と読み）                                | ほかの PDF でも同じ読みにするため    | Chrome の同期用の保存先。多くなって入りきらないときは、このパソコンの中だけ |
| 初めて入れたときの案内を閉じたかどうか                  | 案内を何度も出さないため             | このパソコンの中だけ                                                        |
| 直近のエラー（20 件まで。時刻・起きた場所・エラーの文） | 不具合を知らせてもらうときに使うため | このパソコンの中だけ。エラーの文に URL が入っていても、残す前に消します     |

開いた PDF の履歴は残しません。ただし、リーダーの「Chrome の標準の表示で開く」を押したときは、同じ PDF をもう一度リーダーに移さないよう、そのタブを閉じるか Chrome を終了するまで、その PDF の URL を Chrome の中に覚えておきます。

### Chrome の同期

設定と直した読みは、Chrome の同期用の保存先（`chrome.storage.sync`）に入れます。Chrome の同期をオンにしていると、Chrome が同じ Google アカウントでログインしたほかの Chrome にも同じ内容を届けます（Google のサービスによる同期で、よみがなPDF が送るものではありません）。

きょうだいで同じパソコンを使うときは、Chrome のプロフィールを人ごとに分けてください。

## 通信するもの

よみがなPDF が通信するのは、開く PDF をその PDF のあるサイトから読み込むときだけです。

- 「PDF を開いたら、自動でルビを付ける」で開くときは、Chrome が読み込みかけた PDF を、同じ URL からもう一度読み込みます。ログインが必要なサイトでも開けるよう、そのサイトのログインの情報（Cookie）をそのサイトにだけ付けます。
- URL を貼って開くときは、その URL から PDF を読み込みます。
- 辞書・フォント・PDF を読むためのデータは拡張機能に入っているので、外から読み込みません。

設定の画面の「報告用の情報をコピー」は、拡張機能と Chrome の版、直近のエラーをクリップボードにコピーするだけです。どこにも送りません。貼り付けて送るかどうかは、使う人が決めます。PDF の URL や中身は入りません。

## 権限とその理由

| 権限                                           | 理由                                                                                                                                                                         |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `offscreen`                                    | 漢字の辞書を、画面に出ない拡張機能のページの中で一度だけ読み込むため                                                                                                         |
| `declarativeNetRequestWithHostAccess`          | 許可されたサイトの PDF を、よみがなPDF のリーダーで開き直すため                                                                                                              |
| `storage`                                      | 設定・直した読み・上の表のものを保存するため                                                                                                                                 |
| 「すべてのサイト」へのアクセス（あとから許可） | 設定の画面の「PDF を開いたら、自動でルビを付ける」をオンにしたときだけ求めます。PDF を見分けて、リーダーで開き直すためだけに使います。ページの中身は読み取りも送信もしません |
| 1つのサイトへのアクセス（あとから許可）        | 設定の画面に URL を貼って開くとき、そのサイトの PDF を読み込むために求めます                                                                                                 |
| ファイルの URL へのアクセス（Chrome の設定）   | パソコンに保存した PDF を開いたときも自動でルビを付けたいときだけ、使う人が Chrome の画面でオンにします                                                                      |

## 情報の消し方

- 拡張機能を Chrome から取り除くと、このパソコンに保存したものは消えます。
- 直した読みは、設定の画面の一覧から1つずつ消せます。設定は「設定を最初の状態にもどす」で最初に戻せます。
- 同期したものは、Chrome の設定の「同期と Google サービス」で拡張機能の同期をオフにすると、ほかの Chrome に届かなくなります。Google アカウントに残った同期のデータは、Chrome の同期のデータを消す手順で消せます。
