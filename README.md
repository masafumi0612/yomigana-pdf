# よみがなPDF

ブラウザで開いた PDF に、漢字のよみがな（ルビ）を自動で付ける Chrome 拡張機能です。

> **開発中です。** まだ Chrome ウェブストアには公開していません。

## どんなもの？

読み書きに困難がある子ども（ディスレクシアなど）が、家庭学習で PDF を読むときの手助けを目的にしています。

- PDF を開くだけで、紙面のまま漢字にルビが付きます。縦書きにも対応します。
- 習った漢字にはルビを付けず、まだ習っていない漢字にだけ付けます（小学1年〜6年、中1・中2（目安）、常用漢字すべて、から選べます）。
- 常用漢字にない漢字、「今日」「大人」のような特別な読み方の言葉には、いつもルビを付けます。
- ルビの読みが間違っていたら、その場で直せます。直した読みは、ほかの PDF でも使われます。

## プライバシー

- PDF の中身や設定を、外部に送りません。漢字の読みは、お使いのパソコンの中で調べます。
- 利用状況の計測もしません。

## 動作環境（予定）

- Google Chrome 128 以降（のちに Microsoft Edge にも対応予定）
